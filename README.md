# Deriv Trading Bot - Mmeli_FX

A complete trading bot for Deriv platform with Even/Odd and Over/Under strategies.

## Features
- Connect to Deriv API with personal token
- Fetch account balance
- Even/Odd and Over/Under trading strategies
- Real-time tick data
- Trade history with win/loss tracking
