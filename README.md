# 🤖 Mmeli_FX Deriv Bot

A professional trading bot for Deriv that executes Even/Odd and Over/Under strategies on every tick.

![Deriv Bot](https://img.shields.io/badge/Deriv-Bot-blue)
![WebSocket](https://img.shields.io/badge/WebSocket-1995-green)
![License](https://img.shields.io/badge/License-MIT-yellow)

## ✨ Features

- 🔗 **One-click connect** with Deriv token
- 💰 **Live balance display** updates automatically
- 🎯 **Two trading strategies**: Even/Odd and Over/Under
- 📈 **Real-time tick streaming** via WebSocket (port 1995)
- 📋 **Trade history** with win/loss tracking
- 🔄 **Auto-reconnect** on disconnection
- 💾 **Token persistence** using localStorage
- 📱 **Fully responsive** design
